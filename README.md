# Rock N' Wok — Website V3

Sitio web oficial de Rock N' Wok, comida rápida de inspiración asiática con presencia en Puebla, México.

## Stack

- HTML5 + CSS3 + Vanilla JS — arquitectura single-file
- Fuentes self-hosted: Monument Extended + Gotham (WOFF2)
- Imágenes en formato WebP (optimizadas)
- Deploy: Vercel (static)

## Estructura

```
/
├── index.html          # Aplicación completa (HTML + CSS + JS)
├── assets/             # Imágenes WebP, SVGs
├── dist/
│   ├── favicon*        # Favicon suite
│   └── fonts/          # Monument Extended + Gotham (WOFF2 + OTF)
├── vercel.json         # Configuración de caché y headers
└── .gitignore
```

## Deploy en Vercel
